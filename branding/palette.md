# Brand palette

Working palette for the Seedance Studio plugin. Tweak before final
release; placeholders for now.

| Role    | Hex       | Notes                                |
|---------|-----------|--------------------------------------|
| Ink     | `#111111` | Primary text on light, primary logo. |
| Paper   | `#f7f7f5` | Light background.                    |
| Night   | `#0d0d0f` | Dark background.                     |
| Mist    | `#a6a6a8` | Secondary text on dark.              |
| Accent  | `#ff6b35` | Seedance highlight (sparingly).      |

Typography is system stack only in the README and SVGs (no web fonts
shipped in repo).
