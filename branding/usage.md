# Brand usage

Quick rules for using the Seedance Studio brand assets in derivatives,
forks, blog posts, conference slides.

1. Use the logo and wordmark from this folder. Do not redraw or
   regenerate them.
2. Do not distort, rotate, or recolor the logo. If you need a different
   color, ask: `info@homolapis.ai`.
3. Keep clear space around the logo equal to the height of the "S".
4. Minimum legible size: 24px height for the logo, 120px width for the
   wordmark.
5. If you fork and rebrand, replace these assets in your fork. Do not
   ship the Homo Lapis marks under your fork's name.

These rules are courtesy, not legal restriction beyond what trademark
law already provides for the Homo Lapis name. The plugin code is
GPL-3.0, the brand is not.
